# DailyFlow frontend (Angular 21)

Standalone components, signals, Angular Router (lazy routes), Reactive Forms, HttpClient + auth interceptor, route guards.

```bash
npm install
npm start          # http://localhost:4200  (proxies /api to http://localhost:8080 via proxy.conf.json)
npm run build      # production bundle in dist/frontend/browser
```
See the root README for the full setup.
